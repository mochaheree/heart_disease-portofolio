# 🫀 Heart Disease Risk Profile — Data Analyst Portfolio Project

Hi, I'm Gevan! This project is an end-to-end **Data Analyst case study** using a heart disease dataset.  
The goal is to explore **risk patterns**, highlight key **associations** with heart disease status, and translate findings into a simple monitoring dashboard.

> ⚠️ Note: This analysis focuses on **association, not medical causation**.  
> It’s meant for data insights and decision support, not clinical diagnosis.

---

## ✨ Project Goals
Imagine I’m a Data Analyst in a health/insurance company. The business wants to:
1. Understand **how common** heart disease is in this population.
2. Identify **risk factors** that show strong differences between people with vs without heart disease.
3. Build **risk segments** (low / medium / high) based on lifestyle & biomarker patterns.
4. Provide a **dashboard** so stakeholders can monitor risk distribution easily.

---

## ❓ Business Questions
This project tries to answer questions like:
- What is the **prevalence** of heart disease in the dataset?
- Which **biomarkers** (cholesterol, blood pressure, BMI, triglycerides, etc.) differ the most between groups?
- Which **lifestyle factors** (smoking, alcohol, exercise, stress, sleep, diabetes, family history) are most associated with heart disease status?
- Are there **high-risk combinations** of factors that stand out?
- Can we create simple **risk segments** to prioritize prevention programs?

---

## 📦 Dataset Overview
- Rows: **10,000**
- Columns: **21**
- Target label: **`Heart Disease Status` (Yes/No)**
- Data types: mix of numeric + categorical features
- Missing values: present in several columns (**~0.2–0.3% per affected column**)

Dataset fields include:
- **Demographics:** Age, Gender  
- **Lifestyle:** Smoking, Alcohol Consumption, Exercise Habits, Stress Level, Sleep Hours, Diet  
- **Clinical/Biomarkers:** Blood Pressure, Cholesterol, BMI, Triglyceride Level, Glucose, etc.
